SPECS 是规格目录, 这里的文件由 `/archive` 技能生成, 归档一个需求后(cooking 里面的), 会把其中的规格文件移动到这个目录下, 并建立索引. 这个目录含了所有走功能流程的规格文件, 这个目录有一个 index.md 文件, 里面包含了所有规格文件的介绍和索引, 和所有的上下文工程的底层逻辑一样, 这些规格文件在某些时候用作 agent 的参考, 但是不能全部一股脑的加载到上下文中, 所以 index.md 的文件作用就是告诉 agent, 所有的这些规格文件是干嘛的, 但是先不加载, 而是在需要的时候再读取, 以便于读取上下文, 以便于适应比较大型的项目, 很推荐按照以下结构去组织(按模块分):

```
SPECS/
├── index.md # 索引文件
├── <模块2>/
│   ├── index.md # 二级索引文件
│   ├── <xxx>.md
│   ├── <yyy>.md
├── <模块2>/
│   ├── index.md # 二级索引文件
│   ├── ...

```
