# Svelte 5.x

本文件适用于 **5.x**。只采用 **≤ 项目 minor** 的小节。例如装的是 `5.28`：不要用 5.29 的 `{@attach}`。

## 5.0 基线

```svelte
<script>
  let { title, count = 0, value = $bindable() } = $props()
  let items = $state([])
  let payload = $state.raw(/** API 响应 */ {})
  let filtered = $derived(items.filter((x) => x.ok))
  let total = $derived.by(() => items.reduce((a, x) => a + x.n, 0))
</script>

<button onclick={() => (count += 1)}>{title}: {count}</button>
{#each filtered as item (item.id)}
  <input bind:value={item.name} />
{/each}
```

- `$props()` 可整体接，也可解构；fallback 不是深层代理。
- `$bindable()` 才允许 `bind:foo`。默认值绑定必须传非 `undefined`。
- 组件实例方法：`bind:this={comp}` 再 `comp.foo()`，不要 `bind:foo` 绑 export。
- 可导出、且不读组件 state 的 snippet，可放进 `<script module>`。

## 自 5.13

`unmount(comp, { outro: true })` 会等退场过渡。不要假定 `unmount` 同步完事。

## 自 5.20

表单 / 无障碍 id 用 `$props.id()`，SSR/CSR 稳定。禁止 `Math.random()`。

```svelte
<script>
  const uid = $props.id()
</script>
<label for="{uid}-name">姓名</label>
<input id="{uid}-name" />
```

## 自 5.25

`$derived` 可临时赋值（须 `let`，不要 `const`），适合乐观 UI；依赖更新后会按表达式重算。5.25 之前 derived 只读，乐观更新用单独 `$state`。

```svelte
<script>
  let { post, like } = $props()
  let likes = $derived(post.likes)
  async function onclick() {
    likes += 1
    try {
      await like()
    } catch {
      likes -= 1
    }
  }
</script>
```

## 自 5.29

元素副作用用 `{@attach}`，不要新写 `use:action`。库只给 action 时用 `fromAction`。

```svelte
<script>
  import type { Attachment } from 'svelte/attachments'
  const tooltip =
    (content: string): Attachment =>
    (el) => {
      const t = tippy(el, { content })
      return () => t.destroy()
    }
</script>
<button {@attach tooltip(text)}>Hover</button>
<canvas
  {@attach (canvas) => {
    const ctx = canvas.getContext('2d')
    $effect(() => {
      ctx.fillStyle = color
      ctx.fillRect(0, 0, canvas.width, canvas.height)
    })
  }}
></canvas>
```

`{@attach enabled && fn}`：falsy 就是没有 attachment。组件要转发时把 rest props spread 到根元素。

## 自 5.36

组件内 `await` / `hydratable` 仍走 `experimental.async`，**默认业务代码不要开**。项目 `svelte.config.js` 已启用再写；否则把 Promise 放 load 函数 / 普通 `.ts`。

## 自 5.40

跨层状态用 `createContext`，不要 `setContext` + 字符串 key。

```ts
import { createContext } from 'svelte'

export const [getUser, setUser] = createContext<User>()
```

`get` 在没有父级 `set` 时抛错。模块级 `$state` 仍然不要用来存用户数据（SSR 串请求）。改 context 里的对象要改字段，不要换掉整个引用把链路掐断。

## 自 5.41

`$state.eager(value)` 只用于 await 同步更新期间、必须立刻给的点击反馈（如导航 `aria-current`）。不要拿来驱动关键业务状态。

## 自 5.49

测依赖 context 的组件：用包装函数当 `mount` 的 component，在 wrapper 里 `setXxx(...)` 再渲染目标组件。
