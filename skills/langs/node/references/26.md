# Node 26

本文件适用于 **26.x**（Current；2026-10 才进 LTS）。按下面写。25 并入 26 的能力标在 26.0，不要去读奇数版本 changelog。

## 22/24 仍该用（不必打开旧档）

- ESM 优先；JSON 用 `with { type: 'json' }`
- 全局 `fetch`、`WebSocket`；`node --watch`；没有 Jest/Vitest 就 `node:test`
- `require(esm)` 默认同步加载无 TLA 的 ESM（返回 namespace / `"module.exports"`）
- 可擦除 TS：`node app.ts`（配合 `erasableSyntaxOnly`）；**不做**类型检查
- `fs.glob` / `fs.globSync`
- `Set` 集合方法、`Array.fromAsync`、iterator helpers
- `using` / `await using`、`Promise.try`、`RegExp.escape`、`Error.isError`、`Float16Array`
- `URLPattern` 全局（**仍实验**）
- `AsyncLocalStorage` 的 AsyncContextFrame 默认实现
- `node:sqlite` 的 `DatabaseSync`（见下：RC，不是 Stability 2）
- 子测试不用 `await t.test` 来防父测试提前结束

## 26.0

### require(esm)

**稳定默认**（25.4 起）。关掉用 `--no-require-module`。有 top-level await 的图仍不能被 `require()`。新代码继续 ESM 优先，不要为了 CJS 再包一层。

### type stripping

**稳定且默认**。关掉用 `--no-strip-types`。

**`--experimental-transform-types` 已删除**。`enum`、带运行时的 `namespace`、参数属性、import alias 会 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`。改成可擦除写法，或走 `tsc` / 构建；不要在启动脚本里留这个旗标。

```ts
const Kind = { A: 'A', B: 'B' } as const
type Kind = (typeof Kind)[keyof typeof Kind]
```

不要：

```ts
enum Kind { A, B }
class C { constructor(private x: string) {} }
```

### node:sqlite

官方 **Stability 1.2 RC**（25.7 起），**不是** Stability 2。脚本 / CLI / 测试夹具优先 `node:sqlite`，少装 `better-sqlite3`。API 同步；高并发写仍慎用。`defensive` 默认 true；忙等用 `timeout`。

```js
import { DatabaseSync } from 'node:sqlite'
const db = new DatabaseSync(':memory:')
```

### node:test

默认测试栈（除非项目已有 Jest/Vitest）。`node --test`。子测试自动纳入父测试生命周期。

### V8 14.6

日期时间用 **`Temporal`**（26.0 默认开），新代码不要再堆 `Date` 时区黑客。

```js
const instant = Temporal.Now.instant()
const zdt = instant.toZonedDateTimeISO('Asia/Shanghai')
```

Map/WeakMap 用 `getOrInsert` / `getOrInsertComputed`，不要手写 get-or-set。多段迭代器用 `Iterator.concat`，不要先拼中间数组。

```js
map.getOrInsert(key, defaultValue)
map.getOrInsertComputed(key, () => create())
Iterator.concat(a, b)
```

### 不要碰的 26.0 破坏

- `http.Server.prototype.writeHeader()` 已移除 → `writeHead()`
- 遗留 `_stream_*` 模块已移除
- `module.register()` **运行时弃用**；加载器跟项目现有方式，不要在新代码里新加它
- 不要再传 `--experimental-transform-types`
