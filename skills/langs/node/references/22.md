# Node 22

本文件只适用于 **22.x**。按项目 **minor** 只用该节及更早；不要把 22.0 当成 22.18。

不要用 24/26 才有或才稳定的行为：`URLPattern` 全局、`using` / `await using`、`Promise.try`、`RegExp.escape`、`Error.isError`、全局 `Float16Array`、`Temporal`、`Map.getOrInsert`、`Iterator.concat`、子测试自动 await、把 `node:sqlite` 当成 RC/稳定、把 `require(esm)` / type stripping 当成 Stability 2、已删除的 `--experimental-transform-types`、`--no-strip-types` / `--no-require-module`（22 仍是 `--no-experimental-*`）。

## 22.0

V8 12.4：用 `Array.fromAsync`、`Set` 集合方法（`union` / `intersection` / `difference` / `symmetricDifference` / `isSubsetOf` / `isSupersetOf` / `isDisjointFrom`）、iterator helpers。不要为这些再装 polyfill。

`WebSocket` 全局默认开（去掉 `--experimental-websocket`），**此时仍实验**。`node --watch` **已稳定**。`fs.glob` / `fs.globSync` 可用。

`require(esm)` 必须加 `--experimental-require-module`。图必须全同步（不能有 top-level await），否则 `ERR_REQUIRE_ASYNC_MODULE`。返回值是 namespace（默认导出在 `.default`）。

```js
// node --experimental-require-module app.cjs
const mod = require('./esm-lib.mjs')
mod.default
```

`node --run <script>` **实验**：跑 `package.json` 的 `scripts`，行为刻意小于 `npm run`。

## 22.3

`--run` 会向上找 `package.json`，并给祖先 `node_modules/.bin` 加进 `PATH`。

## 22.4

`WebSocket` **稳定**。客户端用全局 `WebSocket`，不要装 `ws`。`--run` 升到 RC，仍不要拿它当完整包管理器。

## 22.5

`node:sqlite` 落地，**必须** `--experimental-sqlite`。同步 API：`DatabaseSync`。脚本/夹具可以试；生产与高并发写不要当默认。

```js
import { DatabaseSync } from 'node:sqlite'
const db = new DatabaseSync(':memory:')
db.exec('CREATE TABLE t (id INTEGER PRIMARY KEY, name TEXT) STRICT')
const ins = db.prepare('INSERT INTO t (name) VALUES (?)')
ins.run('ada')
```

不要 `import sqlite from 'sqlite'`（必须 `node:` 前缀）。

## 22.6

`--experimental-strip-types`：Node 只擦除可擦除语法（注解、`interface`、`import type`），不读 `tsconfig.json`，不类型检查。`.tsx` 不支持。`node_modules` 里的 `.ts` 会拒跑。

```bash
node --experimental-strip-types app.ts
```

`enum` / 带运行时代码的 `namespace` / 参数属性 / import alias：**会报错**。不要假定能跑。

## 22.7

`--experimental-transform-types`：把上面那些要生成 JS 的语法转掉。默认项目不要靠它；能擦除就擦除，否则走构建。开了会出实验警告。

## 22.12

`require(esm)` **默认开**，仍实验（Stability 1.2）。可 `--no-experimental-require-module` 关掉。检测：`process.features.require_module`。包可用 `"module-sync"` exports condition。

支持 ESM 侧 `export { value as "module.exports" }` 做 CJS 互操作。

此时 **app 代码** `require(esm)` 仍可能打实验警告（`node_modules` 内已压制）。不要当成已稳定。

## 22.13

`node:sqlite` **去掉** `--experimental-sqlite`，**仍实验**（1.1，导入会 `ExperimentalWarning`）。`require(esm)` 默认不再警告（`--trace-require-module` 仍可打）。

## 22.16

`new DatabaseSync(path, { timeout })`：忙等锁，默认 `0`（锁住立即报错）。需要等待就显式设毫秒。

## 22.18

type stripping **默认开且不再警告**，仍实验（22 线最新是 1.2 RC，不是 Stability 2）。关掉用 `--no-experimental-strip-types`。可擦除的 `.ts` 直接：

```bash
node app.ts
```

配合 TS：`erasableSyntaxOnly` + `verbatimModuleSyntax`（细节归 TypeScript 技能）。`enum` 等仍要 `--experimental-transform-types` 或构建——**不要**当成 26 那样旗标已删除。

sqlite 构造函数增加一批选项（`readBigInts`、`returnArrays` 等）。仍实验，不要当稳定存储层。
