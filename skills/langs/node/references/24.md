# Node 24

本文件适用于 **24.x**。按项目 **minor** 只用该节及更早。22 档里已稳定、现在仍该用的（`fetch`、`WebSocket`、`--watch`、V8 12.4 的 `Set` 方法 / `Array.fromAsync` / iterator helpers、ESM 优先）直接用，不必再打开 22.md。

不要用 26 才有的：`Temporal` 默认全局、`Map.prototype.getOrInsert` / `getOrInsertComputed`、`Iterator.concat`、把 `--experimental-transform-types` 当成已删除、`module.register()` 运行时弃用、`http.Server.prototype.writeHeader` 已移除。

## 24.0

V8 13.6：用 `using` / `await using` 关资源；用 `RegExp.escape`、`Error.isError`、全局 `Float16Array`。不要为这些写垫片。`Promise.try` 已在运行时（随 23 的 V8 进来），同步抛错和 thenable 都收进 Promise。

```js
import { open } from 'node:fs/promises'
await using fh = await open('a.txt', 'r')
Promise.try(() => JSON.parse(raw)).catch(onErr)
```

`URLPattern` **全局可用**（仍实验，Stability 1）。不要 `import { URLPattern } from 'node:url'` 才用；22 没有这个全局。

```js
const p = new URLPattern({ pathname: '/api/:id' })
p.test('https://example.com/api/1')
```

`AsyncLocalStorage` 默认 `AsyncContextFrame`。不要为「旧 async_hooks 实现」写兼容；只有回归才 `--no-async-context-frame`。

权限模型旗标改为 `--permission`（不再是 `--experimental-permission`）。

`node:sqlite`：无需 flag，**仍实验**（导入仍可能警告）。构造函数有 `timeout`（默认 `0`）。高并发写不要默认它。

`require(esm)`：默认开、默认无警告，**24.0 仍实验**。关掉用 `--no-experimental-require-module`。有 TLA 的图仍 `ERR_REQUIRE_ASYNC_MODULE`。

type stripping：默认开（自 23.6），**24.0–24.2 仍实验且会警告**。关掉用 `--no-experimental-strip-types`。`--experimental-transform-types` **还在**；`enum` / 参数属性不要当已禁止该旗标。

`node:test`：24.0 曾改成子测试自动等待并让 `t.test()` 不再返回 Promise，随后因破坏面回滚。 **24.0–24.2 不要假设自动 await**；子测试继续 `await t.test(...)`。

## 24.3

type stripping **不再打实验警告**（仍未标 Stability 2）。

子测试 **自动等待父测试结束**（本 minor 重新落地；24.0 那次随后被回滚）。不要再手写 `await t.test` 只为防止「父测试先结束」。`await` 也不再保证「下一行执行前子测试已跑完」——子测试之间的串行逻辑放到钩子，别依赖这个 await。

```js
import { test } from 'node:test'
import assert from 'node:assert/strict'

test('parent', (t) => {
  t.test('a', () => assert.equal(1, 1))
  t.test('b', () => assert.equal(2, 2))
})
```

## 24.12

type stripping **稳定**（Stability 2）。关掉旗标改名为 `--no-strip-types`（不再用 `--no-experimental-strip-types`）。`--experimental-transform-types` 仍在。

sqlite 增加 `defensive` 选项，**此时默认仍未打开**。

## 24.14

sqlite `defensive` **默认 true**：禁止用普通 SQL 故意损坏库文件。需要旧行为显式 `defensive: false` 或 `enableDefensive(false)`。

## 24.15

`require(esm)` **不再实验**（从 25.4 回落到本 minor）。关掉用 `--no-require-module`（`--no-experimental-require-module` 只是别名）。

`node:sqlite` 升到 **Stability 1.2 RC**（不是 2）。脚本 / CLI / 测试夹具优先用它，而不是再加 `better-sqlite3`；高并发写仍慎用。
