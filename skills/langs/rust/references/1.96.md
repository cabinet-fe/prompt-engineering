# Rust 1.96

本文件适用于 **rustc 1.96.x**。1.95 仍该用的写法继续用（if-let guard、`cfg_select!`、`push_mut` 等）。不要把 1.97 才发生的事当成已生效：

- 默认 v0 symbol mangling（1.96 仍是旧 Itanium 风格默认；可选用 `-Csymbol-mangling-version=v0`，但不是默认）
- `pin!(x)` 禁止 deref coerce（`x: &mut T` 在 1.96 仍可能误得到 `Pin<&mut T>`）
- `Result<T, 不可居类型>` / `ControlFlow<不可居, T>` 对 must-use 等同 `T`
- 更多 trailing `self`（`use foo::self`）
- `u32::isolate_highest_one` / `bit_width` / `highest_one` 等
- Cargo `build.warnings`、`resolver.lockfile-path`、`-m`
- `std::char::MAX` 等弃用

## 宏：`cfg` 接 `expr` metavariable

声明宏可以把 `$e:expr` 直接塞进 `cfg` / `cfg_attr` / `cfg!`。谓词能 parse 才合法。

```rust
macro_rules! gated {
    ($pred:expr) => {
        #[cfg($pred)]
        fn enabled() {}
        #[cfg(not($pred))]
        fn enabled() { panic!() }
    };
}
gated!(any(unix, feature = "foo"));
```

## never type 与 `ManuallyDrop`

元组表达式里 `!` **总会** coerce，不要再为 `(loop {},)` 这类写法绕一层。

`ManuallyDrop` 常量可作 pattern（修 1.94 回归）。该 match 就 match，不要改成 `==` 绕开。

## `assert_matches!`

不在 prelude（会撞第三方宏），从 `core` / `std` 显式 import。比 `assert!(matches!(..))` 更能打印实际值。

```rust
use std::assert_matches;
assert_matches!(get_n(), 1..=6);
assert_matches!(a, Some(x) if x > 100);
```

## Copy range（`core::range`）

1.95 已有 `RangeInclusive`。1.96 补齐：

- `core::range::Range` / `RangeIter`
- `core::range::RangeFrom` / `RangeFromIter`
- `core::range::RangeToInclusive` / `RangeToInclusiveIter`

实现 `Copy` + `IntoIterator`（不是 `Iterator`）。公开 API 用 `impl RangeBounds` 同时吃新旧类型；要具体类型时用新 range。`0..1` 语法**仍**产生旧 `core::ops::Range`，未来 edition 才会切。

```rust
use core::range::Range;

#[derive(Clone, Copy)]
pub struct Span(Range<usize>);

impl Span {
    pub fn of(self, s: &str) -> &str {
        &s[self.0]
    }
}
```

新 `RangeInclusive` 字段公开。库代码不要拆 `start`/`end` 只为了让结构体 `Copy`。

## `NonZero*` 区间迭代

`Step` 已实现。直接 `for n in a..b` / `a..=b`，元素类型是 `NonZero*`，不要循环里 `new` / `new_unchecked`。

```rust
use std::num::NonZeroU8;
let a = NonZeroU8::new(1).unwrap();
let b = NonZeroU8::new(4).unwrap();
for n in a..=b {
    let _ = n.get();
}
```

## 其它库 / Cargo

- `LazyCell` / `LazyLock` / `AssertUnwindSafe` 实现了 `From<T>`：值已经算好就 `LazyLock::from(v)`，不要包一层 `|| v`。
- wasm 目标不再给链接器传 `--allow-undefined`。缺符号是链接错误。旧行为才加 `RUSTFLAGS=-Clink-arg=--allow-undefined`。
- 不要写 `use SomeStruct::{self as Other};`（`{self}` 只允许模块父路径）。
- `BTreeMap::append` 对错误 `Ord` 可能 panic：自己的 key 必须遵守序约定。
- 1.96.0 修了第三方 registry 的 CVE-2026-5222 / 5223（crates.io 用户不受影响）。不改写法。

## 1.96.1（2026-06-30）

不改语言、不改推荐写法。升补丁即可：

- rustc：修 MIR 优化误编译
- Cargo：timeout/retry 行为；libssh2 的 CVE-2025-15661 / CVE-2026-55199 / CVE-2026-55200
