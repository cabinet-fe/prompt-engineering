# Rust 1.95

本文件只适用于 **rustc 1.95.x**。不要用 1.96/1.97 才有的 API 与行为：

- `assert_matches!` / `debug_assert_matches!`
- `core::range::{Range, RangeFrom, RangeToInclusive}`（`RangeInclusive` 可用）
- 宏里把 `$e:expr` 传给 `cfg` / `cfg_attr`
- `NonZero*` 整数区间直接 `for` 迭代
- 默认 v0 mangling、`pin!(&mut T)` 的 deref 修复
- `u32::isolate_highest_one` / `bit_width` / `highest_one` 等
- `Result<T, !>` 免 `unused_must_use`、`use foo::self` 这种 trailing self
- Cargo `build.warnings` / `resolver.lockfile-path` / `-m`

无 1.95.1。无小版本语言增量。

## if-let guard

`match` 臂用 `if let`，替代嵌套 match。guard 里绑到的名字在臂内可用。与普通 `if` guard 一样，**不**参与穷尽性检查。同一臂不要同时写 `if` 和 `if let`。

```rust
match value {
    Some(x) if let Ok(y) = compute(x) => {
        println!("{x}, {y}");
    }
    _ => {}
}
```

let chains 上 `irrefutable_let_patterns` 不再误报。不可反驳的 `let` 链式写就行，不要为消 lint 改嵌套。

## 路径关键字重命名

`super` / `crate` / `self` 作路径段时，**必须** `as` 重命名才能 `use`：

```rust
use super as parent;
use crate as this_crate;
```

`use super;` 仍非法。`use $crate::{self};` 无重命名也不再允许。

## const 提升

含易失败运算的表达式，若能否隐式 promote 取决于某个 **const block 的求值结果**，1.95 起**不再**隐式提升。需要 `'static` / 常量化时，整段写成 `const` 项或显式 `const { ... }`，不要赌隐式 promote。

## 兼容

- struct 模式字段简写里，`mut ref` / `mut ref mut` 曾误稳定，现已重新门控。稳定代码不要写。
- `#[non_exhaustive]` 枚举即使只有一个变体，`match` 也会读 discriminant；闭包可能因此多捕获。
- 自定义 JSON target spec 已从稳定通道拿掉，需要 `-Z unstable-options`（日常项目不要碰）。

## 日常 API

**`cfg_select!`**：编译期按 `cfg` 选第一支为真的臂，取代新代码里的 `cfg-if`。可当表达式。无匹配且无 `_` 则 `compile_error`。

```rust
let os = cfg_select! {
    unix => "unix",
    windows => "windows",
    _ => "other",
};
```

**`Vec::push_mut` / `insert_mut`**（`VecDeque` / `LinkedList` 有对应 `*_mut`）：插入并拿 `&mut T`，不要 `push` 再 `last_mut().unwrap()`。

```rust
let last = vec.push_mut(3);
*last += 1;
```

**`core::range::RangeInclusive`**：Copy 的新 range（RFC 3550 首批）。公开 API 优先 `impl RangeBounds`。`1..=3` 语法此时仍是旧 `core::ops` 类型。不要用尚未稳定的 `core::range::Range`。

**`Atomic*::update` / `try_update`**：两个 `Ordering`（成功 store / 失败 load），与 `compare_exchange` 相同。新代码用它们，不要再手写 CAS 循环；`fetch_update` 视为旧名。

```rust
use std::sync::atomic::{AtomicUsize, Ordering};
let x = AtomicUsize::new(7);
assert_eq!(x.update(Ordering::SeqCst, Ordering::SeqCst, |n| n + 1), 7);
```

**`bool::try_from(整数)`**：只接受 0/1。

**`core::hint::cold_path()`**：标冷路径；不要为 likely/unlikely 再拉 crate。

**`MaybeUninit<[T; N]>` ↔ `[MaybeUninit<T>; N]`**：用 `From` / `AsRef` / `AsMut`，不要 `transmute`。
