本文件适用于 **rustc 1.97.x**。按下面写；需要例子再打开 [1.95](1.95.md) / [1.96](1.96.md)。

| 来源 | 用 |
| --- | --- |
| 1.95 | `match` 的 `if let` guard；let chains；`cfg_select!`；`Vec::push_mut`；`Atomic*::update`；`core::range::RangeInclusive`；`hint::cold_path` |

## must-use

`Result<T, 不可居类型>` 与 `ControlFlow<不可居类型, T>` 对 `unused_must_use` **等同 `T`**。错误不可能发生时不要写 `let _ =`。`T` 本身若 must-use（例如内层 `Result`）仍要处理。

```rust
fn never_err() -> Result<i32, std::convert::Infallible> {
    Ok(1)
}
let n = never_err(); // 不要 let _ = never_err();
```

## trailing `self`

`use foo::self` / `use foo::self as bar` 等同 `use foo::{self}` / `use foo::{self as bar}`。非 import 路径也可以 trailing `self`（如 `path::to::Enum::self`）。能写 trailing `self` 就不要强制加一层 `{}`。

## 默认 v0 mangling

稳定通道默认 v0（符号多以 `_R` 开头）。泛型实参保留在符号里，backtrace 文本会变。

- 老 gdb / profiler 可能解不了符号：升级工具，不要假设还能切回 legacy。
- **稳定版不能**再开旧 Itanium mangling；legacy 只剩 nightly，且计划删除。
- 不要为「兼容旧调试器」在稳定 CI 加 `-Csymbol-mangling-version=legacy`（无效）。

## `pin!`

禁止 deref coerce，修 1.88 起的错误允许。`x: &mut T` 时 `pin!(x)` **总是** `Pin<&mut &mut T>`，不是 `Pin<&mut T>`。要 `Pin<&mut T>`：pin 拥有的局部，不要 pin 一个 `&mut`。

```rust
use std::pin::pin;
let mut slot = fut;
let pinned = pin!(slot); // Pin<&mut F>
```

依赖旧 coerce 的代码会编译失败。改调用，不要 `transmute`。

## Cargo

CI 用 `build.warnings`，**不要** `RUSTFLAGS=-Dwarnings`（后者打爆 cache）。

```toml
# .cargo/config.toml 或环境变量
[build]
warnings = "deny"   # warn（默认）| allow | deny
```

```bash
CARGO_BUILD_WARNINGS=deny cargo check --keep-going
CARGO_BUILD_WARNINGS=allow cargo check   # 临时消噪
```

只影响本地包的 lint 警告。`cargo check -m crates/foo/Cargo.toml` 是 `--manifest-path` 的短选项。

只读源码树：`resolver.lockfile-path` 指向已有 `Cargo.lock`（路径必须以 `Cargo.lock` 结尾）。

`cargo clean` 在 `--target-dir` 看起来不像 target 目录时会报错，避免误删。

## 日常 API

整数 / `NonZero*`：`isolate_highest_one` / `isolate_lowest_one` / `highest_one` / `lowest_one` / `bit_width`。手写移位 mask 前先用这些。

```rust
assert_eq!(0b_01100100_u32.isolate_highest_one(), 0b_01000000);
assert_eq!(0b1_0000_u32.highest_one(), Some(4));
assert_eq!(0b111_u32.bit_width(), 3);
```

`char::is_control` 可在 const 上下文用。

## 兼容（会改现有代码）

- **`std::char::{MAX, REPLACEMENT_CHARACTER, UNICODE_VERSION}`** 以及 `from_u32` / `from_digit` / `decode_utf16` 已弃用 → `char::MAX`、`char::from_u32` 等关联项。
- 链接器 stderr 默认以 `linker_messages` lint 发出（**不属于** `warnings` 组）。误报再 `allow`；真问题修链接参数。

```toml
[lints.rust]
linker_messages = "allow"
```

- Windows：socket `shutdown` 写侧后再写，错误是 `BrokenPipe`，不是 `Other`。
- 无 layout 保证的 `enum` 编码可能变；不要依赖未写 `repr` 的判别值。
- struct 模式里元组下标简写会句法拒绝。
