# 新项目

几乎没有业务代码（空仓库、只有 README/license）视为新项目。不要用现有代码当事实来源去「推断」架构。

1. 分类与组织结构见 [classify.md](classify.md)。**描述已能定类别就不要再问类别**；结构或全栈形态不明时只问未决项。
2. 非代码：写完 `PROJECT.md` 后不要做架构 / 规范 / 地图访谈。
3. 代码类：按 [interview.md](interview.md) 分阶段访谈，再写 docs。CODE-MAP 按组织结构写规划目录，问用户模块切分是否对，再落盘；尚未建目录就标明「规划」。

提问一律使用 `交互式提问` 工具，每轮少问、等答完再问下一轮。禁止一次甩出长问卷。
