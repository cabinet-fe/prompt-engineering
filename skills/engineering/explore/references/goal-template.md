# goal.md（固定模板）

路径：`.agents/cooking/<feature>/goal.md`。只使用这些标题。

```markdown
# <短标题>

## 状态

- 确认：未确认

## 对话纪要

- <类型>：<结论>

## 需求目标

<一段话：做什么、给谁、做成什么样算成功。>

## 范围

### 包含

- 

### 不包含

- 

## 决策树

- <本轮类型>
  - Q: <问题> → <决策>
    - 关闭：
    - 打开：

## 未决问题

- 无
```

`确认` 只能是 `未确认` 或 `已确认`。被推翻的树节点留着，补 `作废：<原因>`。

对话纪要：每条一行、只写已钉死结论（`类型：结论`）。禁止复述问答、禁止复制决策树。

决策树：只记已开轮次，一轮一个类型，Q→决策；未开的轮次不预列。未决问题：开局列全部能想到的歧义，钉死一条删一条。
