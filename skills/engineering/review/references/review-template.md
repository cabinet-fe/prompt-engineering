# reviews/Pn.md（固定模板）

路径：`.agents/cooking/<feature>/reviews/Pn.md`。只使用这些标题。

```markdown
# P<n> 评审

## Spec

- 通过 / 不通过
- <证据：哪条验收标准满足或缺失；是否超出范围>

## Standards

- 通过 / 不通过
- <证据：哪条规范；代码类触及 CODE-MAP 契约 1～6 时对应行是否已改>

## 规格影响

- 无命中 / 命中的归档 spec 与结论
- cooking `spec.md` 的「影响文件」能否 parse；新增/删除/修改是否覆盖本阶段实际改动

## 阻塞项

- 无
- 或：必须修完才能通过的条目

## 建议

- 无
- 或不阻塞的改进

## 结论

- 通过 | 不通过
```

「结论」与「评审」状态必须一致。阻塞项非「无」则结论必须是不通过。
