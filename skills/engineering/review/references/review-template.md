# reviews/Pn.md（固定模板）

路径：`.agents/cooking/<feature>/reviews/Pn.md`。只使用这些标题。

```markdown
# P<n> 评审

## Spec

- 通过 / 不通过
- <证据：哪条验收标准满足或缺失；是否超出范围>

## Standards

- 通过 / 不通过
- <证据：哪条规范；CODE-MAP 是否需要但未更新>

## 阻塞项

- 无
- 或：必须修完才能通过的条目

## 建议

- 无
- 或不阻塞的改进

## 结论

- 通过 | 不通过
```

「结论」与「评审」状态必须一致。阻塞项非「无」则结论必须是不通过。
