它解决了什么问题

传统 AI 编程经常遇到“引用废弃 API”、“文档与代码脱节”、“临时任务记录堆积”等痛点。这套技能库给出了务实解法：

文档与代码实时对齐

代码改动如果影响了架构、规范或模块说明，当场直接更新对应文档，确保文档永远不说假话。没受影响的内容绝不乱碰，坚决不建冗余重复的摘要。

精准更新 · 拒绝冗余

识别实际版本，杜绝幻觉

语言和框架技能自动读取项目实际安装版本（如 package.json、go.mod、Cargo.lock），只使用对应版本的官方规范，杜绝凭旧训练数据写出废弃 API。

8 个主流技术栈 · 精确对齐版本

临时过程记录用完即清

开发中的需求讨论与任务拆解仅保存在 cooking/ 临时目录中。全部任务完成后自动清理，只保留最终代码与必要核心文档，保持仓库整洁。

① 安装技能到 Agent

npx skills add cabinet-fe/prompt-engineering
npx skills add cabinet-fe/prompt-engineering --list
npx skills add cabinet-fe/prompt-engineering --skill setup --skill rush
npx skills add cabinet-fe/prompt-engineering -g

支持查看列表、按需挑选技能安装，或全局安装（-g）以在所有项目中生效。

② 两种常见使用方式

# 方式 A：分步执行（适合探索与精细把关）

explore 审批单想支持批量转办
to-spec approval-batch-transfer
to-tasks approval-batch-transfer
implement approval-batch-transfer P1
archive approval-batch-transfer

# 方式 B：全流程自动编排（适合大需求一键跑完）

rush 审批单想支持批量转办

③ 初始化后的项目目录结构

.agents/
├── docs/       项目概况 PROJECT；
│               代码类含架构/规范/地图/坏味道自查
├── scripts/    预检 precheck、任务管理 cooking
│               与规范模板
└── cooking/    临时开发记录（gitignore，不提交）
AGENTS.md       根索引文件，供 AI 按需加载具体文档

若执行过 acceptance 会额外生成 ACCEPTANCE.md 验收规范。任务完成后 cooking/ 临时记录会自动清除。
